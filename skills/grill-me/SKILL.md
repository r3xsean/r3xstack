name: grill-me
description: Use when the user says "grill me", or another skill asks for a grill.
---

Settle with the user the decisions about a request, plan or idea that only they can make, and nothing else.

## What's theirs

Ask a question only when its plausible answers would materially change what the user gets: what they see it do, compatibility, scope, a tradeoff they'd accept, or the cost to ship. Don't ask when the request, a recorded decision, or the user leaving that decision to you already settles it; being asked for a grill leaves nothing to you. Don't ask whether to keep something as it is when nothing you found argues for changing it; list those in one line of what stays, so the user can object. Find facts yourself, by looking or trying. Current behaviour shows what exists, and settles what's wanted only where the request or a recorded decision keeps it. How it's built is yours unless the user puts the mechanism in question; when a choice of how brings such a tradeoff, ask about its consequence, not the mechanism.

## Asking

Ask in rounds, each as one plain chat message; never use your question tool. A round holds every open question that doesn't wait on another's answer, numbered, each with your recommended answer and worded so "yes" accepts it; a bare "yes" accepts the whole round. A question that depends on one still open waits for a later round. Wait for the answers before the next round. There's no cap on questions.

## Done

Done when no question that qualifies is open. Reply with each decision and its answer, marking those the user left to you; when nothing qualified, say so in one line and ask nothing. When the user invoked this directly, that reply ends your turn and approves nothing; when another skill called it, that skill says what comes next.
